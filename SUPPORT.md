# NovaChat Support

NovaChat is currently alpha software. Before reporting a problem:

1. Update to the newest public release.
2. Read [INSTALL.md](INSTALL.md) for NovaChat installation help.
3. Read [RELAY_INSTALL.md](RELAY_INSTALL.md) for NovaRelay setup and network help.
4. Remove passwords, private keys, public IP addresses, message contents and other personal information from screenshots and logs.

## Report a bug

Use the [NovaChat bug report form](https://github.com/ufukmehmedov/NovaChat-Releases/issues/new?template=bug_report.yml).

Include the platform, NovaChat or NovaRelay version, what you expected, what happened and exact reproduction steps. Logs are helpful only after secrets and personal information have been removed.

## Request a feature

Use the [feature request form](https://github.com/ufukmehmedov/NovaChat-Releases/issues/new?template=feature_request.yml).

## Security problems

Do not disclose vulnerabilities, relay passwords, cryptographic keys or private user data in a public issue. Follow [SECURITY.md](SECURITY.md).
